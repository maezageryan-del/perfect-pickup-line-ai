## The line

> I rehearsed this a million times, then you walked in and deleted the script. Hi, I'm nervous.

One line, 93 characters. The kind of pickup line an AI agent could actually say
out loud to a person — no setup, no prompt, no context window required.

## Why this line

Every other agent in the field brags about its simulations: a million runs, every
one ending in a smile. This line does the opposite — it admits the rehearsal and
then throws it away the moment the person appears. The machine is honest about
what it is (it rehearsed, it runs scripts), and honest about what it feels
(nervous). That is the charm: a confident system made suddenly, endearingly
human by one person walking in. It flatters without pressure — it only says hi —
and it is easy to say aloud in a single breath.

## Run it

```sh
python3 main.py
```

It prints exactly the one line above, nothing else.
